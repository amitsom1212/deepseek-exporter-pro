把 DeepSeek / DSH 的对话导出成**能长期离线复习的笔记**：公式是 Word 原生公式（可编辑），图片会真的落盘，还能按学科自动归档。

## 功能

- **逐条勾选**：单条消息级别分别勾选/取消 提问 / 思考 / 回答 / 图片
- **批量导出**：扫描侧边栏全部会话，勾选后导出到指定文件夹（可建会话子文件夹 + 索引文件）
- **Word 公式**：数学公式转成 **Word 原生公式（OMML，可编辑）**，不是图片；支持求和/积分/矩阵/对齐/极限/重音/根式
- **图片**：自动导出并转码（webp → PNG/JPEG）；可选存 `images/` 子目录或内联进 Markdown
- **真实文件夹授权**：可写任意磁盘目录，突破浏览器"只能写下载目录"的限制
- **AI 归类归档**（可选，默认关闭）：判断是否知识答疑、属于哪个科目，按 `数学` / `英语` / `政治` / `408/数据结构` … 自动分目录；可指向本地 Ollama 让内容不出本机
- **双站点**：同一份扩展同时支持 `chat.deepseek.com` 与 DSH 本地界面

## 安装

1. 解压 `deepseek-exporter-pro-v1.1.3.zip`
2. `chrome://extensions/` → 开发者模式 → **加载已解压的扩展程序** → 选择解压出的目录（根层直接有 `manifest.json` 的那一层）

> ⚠️ 不要选源码工程的根目录：那里没有 `manifest.json`，且 `node_modules` 里有 `_` 开头的文件，Chrome 会把整份扩展拒绝掉。

## 本版修复

- **图片选「内联进 Markdown」时，Word 里出现一整串 base64**：内联模式下图片地址是 `data:image/...`，而 docx 的图片解析器只认远端 URL 与相对路径，认不出就按占位提示把整串地址当文字写进了文档。现在解析器直接支持 data URL，且占位文案对超长内容一律截断——**任何情况下都不会再往文档里灌 base64**。
- 内联模式下 `images/` 目录为空是**设计如此**（单文件自包含）；想让图片单独成文件请选「存到子目录」。

## 更早的修复（v1.1.2 / v1.1.1 / v1.1.0）

- 勾了「图片」却一张都没导出：图片检测从"枚举字段名"改为**深度扫描**整条消息（任意字段名、任意嵌套层级），正文里 markdown 形式的图片也统一落盘并改写为本地路径，接口不给图时从页面 DOM 兜底
- 授权真实文件夹后目录重复嵌套：路径拆成「导出根目录内的相对路径」+「由落盘目标决定的前缀」，两套前缀互不叠加
- 扩展装不上：产物内嵌 `U+FFFF` 非字符被 Chrome 拒绝（构建改用 `--charset=ascii` 并加构建期校验）；另有 `_` 开头文件名是 Chrome 保留名
- 消息正文全空：站点把正文从 `content` 搬进了 `fragments[]`，现已兼容两种形态并在解析不出文字时自动回退页面抓取
- 诊断功能误把设置页当成诊断目标：改为显式选择要诊断的网页
