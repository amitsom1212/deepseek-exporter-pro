Markdown → Word (.docx)

离线可用 · 数学公式转成 Word 原生可编辑公式 · 不联网、不上传

① 粘贴 Markdown 或拖入 .md 文件

把 .md / .markdown / .txt 文件拖到这里，或点击选择文件

② 选项

公式支持：分数、根式、上下标、求和/积分（含上下限）、矩阵、对齐环境、希腊字母、重音（向量/横线/尖帽）。 转换后是 Word 原生公式，可以在 Word 里直接改。

③ 用法

  1. 把 ChatGPT / DeepSeek / 任何地方的 Markdown 粘进左边。
  2. 点「转换并下载 .docx」，浏览器会直接下载 Word 文件。
  3. 本页面完全离线：不会发送任何数据到网络。

也可以在其它网页/脚本里调用同目录下的 md2docx.js：
MdToDocx.mdToDocx(md).then(blob => ...)
